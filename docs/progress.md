## 막차 계산 방식

```
역 고르기 ─┬─ 같은 노선 ── /api/last-train ── 1~9호선: 서울 시간표 (열차 번호로 도착역 통과 판정)
           │                                └─ 그 외: TAGO 시간표 (역 ID 번호 순서로 판정)
           └─ 다른 노선 ── /api/plan ── 카카오 경로 → 구간별 시간표 → 마지막 구간부터 역산
```

- **출발 시각 = 막차 − 도보 − 5분.** 운행일 경계는 04:00이다. 00:30 막차는 전날 운행의 24:30으로 계산한다.
- **시간표 출처**

| 노선 | 출처 | 토요일 |
|---|---|---|
| 1~9호선 | 서울 열린데이터광장 (OA-101) | 있음 |
| 그 외 (신분당·수인분당·공항철도 등) | TAGO | 없음 → 휴일 시간표로 대신하고 화면에 표시 |
| 부산 | TAGO | 있음 |

- **휴일 시간표로 대신하는 근거:** 서울교통공사·코레일·9호선 6개 역에서 토요일과 휴일 시간표가 열차 번호까지 같았다. 신분당·공항철도는 직접 확인하지 못한 추정이다.
- **판정할 수 없으면 "안 간다"로 본다.** 틀리더라도 더 이른 막차를 알려주는 쪽이 안전하다.
- **환승 도착 시각:** 서울 시간표 구간은 실제 값을 쓴다. 나머지는 카카오 소요시간으로 추정하고 화면에 "(추정)"으로 표시한다.
